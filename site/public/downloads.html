Install help
  1. Setup (Windows): run it. It's signed (the publisher shows as Mei Liu), finds your World of Warcraft folder and installs into _forever_\Interface\AddOns. No admin rights needed.
  2. CurseForge app: open World of Warcraft, pick your Forever install (add your _forever_ folder if it isn't listed) and click Install on the project's page.
  3. ZIP: unzip into World of Warcraft\_forever_\Interface\AddOns (on a Mac, /Applications/World of Warcraft/_forever_/Interface/AddOns), so each folder sits next to LoreForever, not inside it. Updating? Delete the old LoreForever folders first.
  4. Start WoW, or type /reload. Pick your narrator under Options › AddOns › Lore Forever › Narration voices, or type /lore voice. Not showing up? On the character screen, click AddOns and tick Load out of date AddOns. Still stuck? Ask on Discord.
