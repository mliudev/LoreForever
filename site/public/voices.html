Narration voices

Choose who tells the story. In game, open Options › AddOns › Lore Forever and pick a Narration voice, or type /lore voice.

If a voice hasn't recorded a story yet, the default narrator reads it, and anything without a recording is read aloud in the game voice. Prefer no recordings at all? Pick Game voice only.

Installing a voice

  1. Download the voice's zip from this page.
  2. Unzip it. Inside is a folder named LoreForever_Voice_<Name>.
  3. Put that folder in World of Warcraft\_classic_beta_\Interface\AddOns, next to the LoreForever folder.
  4. Restart the game. A /reload isn't enough for the game to find a new add-on.
  5. Open Options › AddOns › Lore Forever, pick the voice under Narration voice, and press Preview.

To go back, pick Default. To remove a voice, delete its folder.

Lend your voice

Want to narrate the stories of Azeroth? You don't need to record everything: start with a few places, and the default narrator covers the rest. We build the pack, listen to it, and publish it here with your name on it.

  1. Read the narrator guide: recording settings, file names, and where to start.
  2. Download the clip list: the text to read and the file name for every narration.
  3. Record at home, put the files in a shared folder, and send us the link.
